# ChainSentinel AI

### AI-Powered Blockchain Security, Anomaly Detection & Digital Forensics

ChainSentinel AI is a Python-based cybersecurity platform designed to investigate blockchain activity, analyse suspicious files, detect abnormal patterns and generate AI-assisted security reports.

## Main Features

- Ethereum blockchain monitoring
- Universal file investigation
- Machine learning anomaly detection
- Wallet behaviour analysis
- AI security analyst powered by Groq
- Transparent risk scoring
- Security alerts
- PDF and CSV investigation reports
- Interactive analytics dashboard

## Technology

- Python
- Streamlit
- Groq API
- Web3.py
- Scikit-learn
- Pandas
- Plotly

## Security

- Secure API key management
- File validation
- SHA-256 evidence hashing
- Safe archive processing
- No execution of uploaded files

## Project Status

Under development.

## Deployment

The application will be deployed using Streamlit Community Cloud.
## Universal File Investigation

Supported formats:

- PDF and DOCX documents
- TXT and RTF text files
- CSV, XLSX and XLS spreadsheets
- JSON and XML data
- LOG and SYSLOG files
- Solidity smart contracts
- PCAP and PCAPNG network captures
- PNG, JPG and JPEG images with OCR
- ZIP archives with safe in-memory inspection

Security controls:

- SHA-256 evidence hashing
- File size validation
- File signature checks
- Safe archive inspection
- Archive nesting and expansion limits
- No execution of uploaded files

Extracted indicators are investigation leads and do not establish malicious activity by themselves.
